# 2026.293.1922 — fix(checks): assert a CPython floor, not one exact minor

## Summary

The two interpreter checks hard-coded one exact minor:

```yaml
- check: the interpreter reports a CPython 3.13 version
  stdout: [{contains: "3.13"}]
- check: … and reports major.minor 3 13
  stdout: [{contains: "3 13"}]
```

That asserts a property of **this layer's own `pixi.toml`** against every image that
composes it — which is not the layer's contract. An image's pixi environment belongs to
whichever candy ships the `pixi.toml` it is built from, so a consumer may legitimately
run a different minor. `open-webui` requires `>=3.11,<3.13` (0.9.5 and 0.12.3 alike),
so the `openwebui` image runs **3.12.13** and its whole check bed stopped at
`check-image` on these two steps — making the *runtime half* of that gate unreachable
for it (opencharly/layer-python#8).

This asserts the floor instead — what the layer actually guarantees:

```yaml
- check: the interpreter is a CPython at or above the supported floor (3.11) — the exact
    minor belongs to whichever candy owns the image's pixi.toml, not to this layer
  exit_status: 0
  stdout: [{contains: "CPython 3."}]
  command: …/python -c "import platform, sys; assert sys.version_info >= (3, 11), sys.version_info; print(platform.python_implementation(), '%d.%d' % sys.version_info[:2])"
- check: the interpreter executes a standard-library snippet (incl. the sqlite3 C extension) and satisfies the same floor
  exit_status: 0
  stdout: [{contains: "stdlib-ok"}]
  command: …/python -c "import sys, json, sqlite3; assert sys.version_info >= (3, 11), sys.version_info; json.dumps([1]); sqlite3.connect(':memory:').execute('select 1').fetchone(); print('stdlib-ok', sys.version_info.major, sys.version_info.minor)"
```

The version enforcement lives **inside the interpreter**, so a missing, Python-2 or
too-old interpreter still fails — the checks are weaker in exactly one dimension (which
minor) and unchanged in the dimensions that matter (it exists, it runs, it has the C
extension). A consumer that needs an exact version asserts it in its own `plan:`.

Docs move with the code (R2): the candy `description:`, a new "Environment ownership"
section in the skill body, and the README all now say the `>=3.13,<3.14` pin is this
layer's **default** and the check is a **floor**.
